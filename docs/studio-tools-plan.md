# Studio Tools roadmap (ชุดที่ 2: เครื่องมือ Studio + แรงบันดาลใจจาก Nava-art + Kit เพิ่มเติม)

เอกสารนี้ออกแบบให้แชท/โมเดลที่ทำงานต่อหยิบไปทำทีละ Phase ได้โดยไม่ต้องย้อนอ่านบทสนทนาเดิม
ใช้คู่กับ `docs/visual-kit-plan.md` (Kit engine ที่ทำไปแล้ว) อย่าแก้ไฟล์นั้นถ้าไม่จำเป็น
ผู้ใช้สื่อสารภาษาไทย **ตอบเป็นภาษาไทยเสมอ**

## กติกา (ย่อจาก CLAUDE.md ใน repo — อ่านไฟล์นั้นด้วย)

1. แก้ `src/template.html` (และ `src/effects/*.js`, `src/worlds.json`) แล้วรัน `python3 src/build_web.py` ห้ามแก้ `index.html` / `assets/` ด้วยมือ
2. ทุก Phase = 1 branch จาก `origin/main` ล่าสุด → commit → push → PR → merge (squash) เข้า `main` โดยไม่ต้องถามซ้ำ
3. หลัง merge รอ deploy (วน curl หน้า index ดู hash ของ `assets/app.*.js`) แล้วเปิดเว็บจริงด้วย Chromium ทั้งจอคอมและมือถือ ยืนยันว่าเห็นผลจริง ก่อนรายงานว่าเสร็จ ถ้าเปิดเว็บจริงไม่ได้ให้บอกตรง ๆ
4. สกรีนช็อตเก็บนอก repo; ทดสอบด้วย Chromium จำลองเท่านั้น → **ต้องบอกผู้ใช้ว่ายังไม่ได้ลองบน iPad/iPhone จริง**
5. ทุกของใหม่ต้อง: อยู่ใน snapshot/undo/redo, Reset ล้างได้, ภาพที่ Save (`composePoster`) ตรงกับจอ, มือถือไม่มี scroll แนวนอน, ปุ่มสัมผัสสูง ≥ 40px
6. ห้ามคัดลอกภาพ โลโก้ ข้อความของผู้ออกแบบต้นฉบับ ใช้ภาพอ้างอิงเป็นแรงบันดาลใจด้านรูปแบบเท่านั้น
7. ใช้สรรพนาม they/them ถ้าไม่ทราบสรรพนามของใคร

## สถานะ ณ ตอนเขียน

- `main` อยู่ราว PR #196; Kit engine (Phase 1–13 ของ visual-kit-plan) ทำไปแล้ว, UI ย่อแล้ว (แผงขวา 262px), แถบแก้ไขเปิดจากไอคอนประแจ (`updateEditBtn`/`openCtxBar`)
- Studio ตอนนี้: คีย์ลัดมีแค่ **V (Move) และ H (Hand)** (บรรทัดที่ `addEventListener('keydown'` มี `k === 'v'`), ยังไม่มี Ctrl+Z บนคีย์บอร์ด
- เลือกหลายชิ้นได้เฉพาะแผง Layers (`selMode`, `multi`, `toggleMulti`, `clearMulti`) — **ไม่มีลากคลุมบน canvas**
- ลากบน canvas ด้วย Move tool = ย้ายดาว (`this.x/this.y` พร้อมแรงเฉื่อย, handler `pointermove` ที่ `canvas.addEventListener`), Hand tool = หมุนดาว (`planet.turn`); `this.shift` เป็นการเลื่อนทั้งโปสเตอร์เมื่อมีแผงเปิด ไม่ใช่การลากของผู้ใช้
- แถบปากกา (`.st-assist`): Pen/Eraser, + New layer (เส้นอยู่ใน layer เดียวกันจนกดเลเยอร์ใหม่ผ่าน `drawCur`), Pen thickness/opacity/สี, กริด + Assisted drawing, hold-to-shape
- Shapes: ช่อง Fill colour (`st.fillOn`) + Opacity + ลายกริด/จุด (`st.pattern`); รูปใหม่เริ่มต้น **ไม่มี fill** (ผู้ใช้ขอไว้ ห้ามเปลี่ยนค่าเริ่มต้น)
- บรรทัดเลื่อนได้ ให้ `grep` ชื่อเมธอดก่อนแก้เสมอ

## การตัดสินใจของผู้ใช้ (ห้ามเปลี่ยนโดยไม่ถาม)

- **ลากคลุมต้องคลุม "ดาว" ได้ด้วย แล้วลากขยับเคลื่อนที่พร้อมกัน** — ดาว (Cerebra) เป็นสมาชิกของการเลือกหลายชิ้นได้ (ดูรายละเอียดใน S3)

## S1 — คีย์ลัด + Undo/Redo บนคีย์บอร์ด (ง่าย ได้ผลทันที)

| กลุ่ม | คีย์ |
|---|---|
| เครื่องมือ | V Move, H Hand, M Select, T Text, P Pen, L Line, E Eraser, S Shapes, F Focus, K Kit |
| แก้ไข | Ctrl/Cmd+Z undo, Shift+Ctrl/Cmd+Z หรือ Ctrl+Y redo, Ctrl+C/V คัดลอก/วาง, Ctrl+D ทำซ้ำ, Delete/Backspace ลบ, Ctrl+A เลือกทั้งหมด |
| จัดการ | Ctrl+G รวมกลุ่ม, Shift+Ctrl+G แยกกลุ่ม, Ctrl+L ล็อก/ปลดล็อก, `[` `]` ส่งลง/ขึ้น 1 ชั้น, Ctrl+`[` `]` ไปล่างสุด/บนสุด |
| ขยับ | ลูกศร ±1px (หน่วยหน้าจอ), Shift+ลูกศร ±10px |
| มุมมอง | Space ค้าง = Hand ชั่วคราว, Ctrl+0 รีเซ็ตมุมมอง (`resetView`), H ซ่อน/แสดง UI (ชนกับ Hand → ให้ใช้ `Tab` ซ่อน UI และคง H = Hand) |
| อื่น ๆ | Esc ยกเลิกเลือก/ปิดเมนู/ปิดแถบแก้ไข, Ctrl+S เปิดเมนู Save (preventDefault), `?` หน้าต่างรายการคีย์ลัด |

- ศูนย์กลางเดียว: ตาราง `SHORTCUTS = [{keys, label, run}]` ใช้ทั้งดักคีย์และสร้างหน้าต่าง `?` และ tooltip ของปุ่ม (ไม่ซ้ำสองที่)
- ข้ามเมื่อโฟกัสอยู่ใน `input,textarea,select,[contenteditable=true]` และเมื่อ Studio ไม่ active; ดัก `preventDefault` เฉพาะคีย์ที่ใช้จริง (Ctrl+S, Ctrl+D, Ctrl+Z ฯลฯ)
- **ผ่านเมื่อ:** กดแต่ละคีย์ทำงานตรงตาราง, พิมพ์ในช่องข้อความไม่ไปกระตุ้นคีย์ลัด, Ctrl+Z/Shift+Ctrl+Z ย้อน/ทำซ้ำถูกต้อง, `?` แสดงรายการ (มือถือไม่ต้องแสดงปุ่ม)
- แรงบันดาลใจ: Nava-art มี keydown handler ใกล้ `selectToolByKey` (B/E/R/S/I/H/G/Space, Ctrl+Z)

## S2 — Fill ใน Shapes: Off / Solid / Soft

- เพิ่มตัวเลือก `fillMode: 'none' | 'solid' | 'soft'` ในเมนู Shapes (flyout `decor`) และในแผง Style (แทน/เสริมช่องติ๊ก `fillOn`; migrate: `fillOn=true` → `solid`)
- **Solid** = สีเต็ม (ตาม Opacity ของรูป); **Soft** = จางอ่อน มี 2 แบบย่อย: `tint` (alpha คงที่ ~15–30%) และ `fade` (ไล่จากขอบเข้าใน หรือกลับกัน ด้วย gradient) ตัวเลื่อน `softAmount`
- สี fill แยกจากสีเส้นได้ (`fillColor`) ค่าเริ่มต้นตามสีเส้น
- รูปใหม่ยัง **เริ่มต้นไม่มี fill**
- จุดโค้ด: `drawShapeSvg` (จอ: SVG `<linearGradient>/<radialGradient>`), `drawShapeCanvas0` (Save: `createLinearGradient/RadialGradient`) ต้องออกมาเหมือนกัน, `addItem` ค่าเริ่มต้น `st`, snapshot/restore เก็บ `st.fillMode`
- **ผ่านเมื่อ:** สลับ 3 โหมดเห็นผลทันที, undo/redo, Copy, Save ตรงกับจอ (ทั้งสี่เหลี่ยมมุมมน/วงกลม/สามเหลี่ยม), Focus shape ไม่มี fill

## S3 — เลือกหลายชิ้น / ลากคลุม (รวม "ดาว")

**พฤติกรรม (ตามที่ผู้ใช้ตัดสินใจ):**
- **PC:** ลากเมาส์บน **พื้นว่าง** = วาดกรอบเลือก (marquee) ไม่ต้องเปิดเครื่องมือ; Shift+ลาก/คลิก = เพิ่ม, Alt+ลาก = ลบออกจากที่เลือก; Ctrl/Cmd+A = ทั้งหมด
- **กรอบเลือกคลุม "ดาว" ได้:** ดาว (Cerebra / ดาวของโลกที่เลือกอยู่) ถือเป็นสมาชิกพิเศษ `PLANET` ของการเลือก; เมื่อกรอบตัดวงของดาว (พื้นที่ประมาณ `planetBase + this.x/this.y` ตามรัศมีบนจอ) ดาวจะถูกเลือกด้วย
- **ลากขยับเคลื่อนที่:** เมื่อเลือกหลายชิ้น (มี/ไม่มีดาว) ลากชิ้นใดชิ้นหนึ่งในกรอบรวม → ทุกชิ้นขยับด้วยระยะเท่ากัน ชิ้นปกติปรับ `it.x/it.y`, ดาวปรับ `this.x/this.y` (หน่วย world, ใช้ตัวคูณ `sx/sy` เดียวกับ handler ลากดาวเดิม) และไม่ใส่แรงเฉื่อยของดาวระหว่างลากกลุ่ม
- **ลากที่ตัวดาวโดยตรง** (ไม่มีกรอบเลือก) ยังย้ายดาวเหมือนเดิม; Hand tool ยังหมุนดาว; **ลากบนพื้นว่างเปลี่ยนจาก "ย้ายดาว" เป็น "กรอบเลือก"** (ผู้ใช้รับทราบ) — ต้องอัปเดตข้อความช่วยเหลือที่บอกวิธีย้ายดาว
- **จอสัมผัส:** เครื่องมือ **Select** ในแถบ Tools (M) มี 2 โหมด: กรอบสี่เหลี่ยม และ Lasso (ลากวงอิสระ); แตะชิ้นเพื่อเพิ่ม/ลบจากที่เลือก (ใช้ `selMode`/`multi` เดิม ติ๊กถูกซิงก์กับแผง Layers)
- เกณฑ์: ตั้งได้ "แตะโดนบางส่วน" (ค่าเริ่มต้น) หรือ "อยู่ในกรอบทั้งชิ้น"; ข้ามชิ้นที่ล็อก/ซ่อน/reference
- เมื่อมีหลายชิ้น: วาดกรอบรวม (bounding box) + ที่จับมุม; ที่จับหมุน/ย่อขยายรวมเป็นขั้นต่อไป (เริ่มที่ย้าย)
- แถบประแจ (โหมดหลายชิ้น): Group, Copy, Delete, Lock, Opacity รวม (คูณสัมพัทธ์), จัดแนว (ซ้าย/กลาง/ขวา/บน/กลาง/ล่าง) + กระจายเท่ากัน — ดาวไม่เข้าร่วม Delete/Group/Copy/Opacity (แสดงเป็นสมาชิกที่ย้ายได้เท่านั้น)
- จุดโค้ด: pointerdown ของ `canvas` (ในคลาสที่มี `this.drag`), `selMode/multi/toggleMulti`, `updateEditBtn` (แสดงประแจที่มุมบนขวาของกรอบรวม), `updateFocus`/`updateRotHandle` หลังย้าย, `commit()` ตอนปล่อย; จุดดาว = `app.core.planet` + ตัวแปร `this.x/this.y`
- **ผ่านเมื่อ:** ลากคลุมเลือกข้อความ+รูปทรง+Kit ได้, คลุมดาวแล้วดาวถูกไฮไลต์, ลากแล้วทุกชิ้นรวมดาวขยับพร้อมกันตรงตามนิ้ว/เมาส์, undo (ถ้าดาวไม่อยู่ใน snapshot ให้เพิ่ม `planetOffset` เข้า snapshot), Save ตรงกับจอ, ลากดาวตรง ๆ ยังทำงาน, ไม่มี scroll/zoom หน้าเว็บบน iPad

## S4 — เครื่องมือเส้นขีด (Line) ในเมนูปากกา + "เส้นเต้น"

- เพิ่มปุ่ม **Line** ในแถบปากกาข้าง Pen/Eraser (คีย์ L); กดหรือลากจากจุด A ไป B ได้เส้น; มีเส้นตัวอย่างระหว่างลาก; Shift = ล็อกมุม 15°; ใช้ Assisted drawing/กริดเดิมสแนป
- **เส้นอยู่ใน layer เดียวกับปากกา** จนกว่าจะกด + New layer (ใช้ `drawCur` เดิม): แต่ละเส้นเป็น record ใน `it.strokes` ที่มี `type:'line'`, จุด A/B (พิกัด 0–1 ของกล่อง item), `motion`, `seed`, และพารามิเตอร์
- **การเคลื่อนไหว (`motion`):** ไม่ขยับ / สั่นแบบวาดมือ (wobble) / คลื่นวิ่งตามเส้น (wave) / หนาบางตามจังหวะ (pulse) / ดีดแบบสาย (pluck: แกว่งแล้วนิ่ง, ดีดซ้ำเมื่อแตะ)
- **ตัวเลือก:** amplitude, frequency/wavelength, speed, damping (pluck), ความหนา, opacity, สี, ชนิดเส้น (ทึบ/ประ/จุด), หัวท้าย (กลม/จุด/ลูกศร/เหลี่ยม), ความโค้ง (bow), seed (ปุ่มสุ่ม)
- **แก้ภายหลัง:** เลือกเส้น (แตะใกล้เส้น) → ลากจุดปลายเพื่อย้าย, แก้ค่าผ่านแถบประแจเฉพาะเส้นนั้น; ค่าล่าสุดเป็นค่าเริ่มต้นของเส้นถัดไป (เก็บใน `drawSet`/localStorage เหมือนปากกา)
- **การวาด:** ใช้ลูปแอนิเมชันเดียว (rAF) วาดเฉพาะเส้นที่ขยับบน canvas overlay และทำงานเมื่อมีเส้นขยับอยู่ + หน้าเห็นอยู่; เส้นที่ไม่ขยับยังเป็น SVG path เดิม; จำกัด ≤ 200 เส้น/layer และ ≤ 120 จุดต่อเส้น (มือถือต่ำกว่า)
- **Save:** ได้เฟรมที่เห็นตอนนั้น (เหมือน Spin ของ Kit: หยุดก่อน Save ถ้าต้องการมุมที่แน่นอน) ส่วนวิดีโอทำใน S6
- จุดโค้ด: handler วาดของปากกา (pointerdown ของ `.st-draw-pad`, `cur`, `strokeD`), `drawShapeCanvas0` สาขา `stroke`, `renderLayers` ชื่อ "Drawing"
- **ผ่านเมื่อ:** ลากจาก A→B ได้เส้นในครั้งเดียว, หลายเส้นอยู่ layer เดียวจนกด New layer, ปรับค่าเห็นผลสด, undo/redo รายเส้น, Eraser ลบเส้นได้, Save ถูกต้อง, ไม่กินแบตเมื่อไม่มีเส้นขยับ

## S5 — Picker, Mood และปุ่มสุ่มลุค (ง่าย)

- **Picker (หยดสี):** ปุ่มข้างช่องสี (ปากกา/รูปทรง/ข้อความ/Kit) แตะแล้วแตะบน canvas เพื่อดึงสีจากภาพ (อ่านจาก canvas ที่ composite; ใช้ `EyeDropper` API ถ้ามี ไม่งั้นอ่านพิกเซลจาก `composePoster(1)` ย่อ) คีย์ I
- **Mood:** พรีเซ็ตทั้งฉาก (พื้นหลัง, สี, แสง, เอฟเฟกต์, พารามิเตอร์ดาว) 4–8 ชุด เช่น Cyberpunk Neon, Deep Ocean Zen, Pastel Dream, Monochromatic Noir (แรงบันดาลใจจาก `MOODS` ใน Nava-art) ต่อยอดจาก `applyPreset`
- **ปุ่มสุ่มลุค (G):** สุ่มสี/พื้นหลัง/เอฟเฟกต์/สไตล์ผิว **ไม่แตะงานที่วางแล้ว** (ข้อความ รูปทรง Kit); undo ได้ครั้งเดียว
- **ผ่านเมื่อ:** แต่ละ Mood เปลี่ยนทั้งฉากและ undo กลับได้, Reset ล้างกลับค่าเริ่มต้น (Glass เป็น 0), สุ่มแล้วงานเดิมไม่เปลี่ยน

## S6 — Save เป็นวิดีโอ / loop

- ใช้ `MediaRecorder` กับ `canvas.captureStream()` ของภาพที่ composite (ต้องมี canvas composite แบบเรียลไทม์: วาดซ้ำ `composePoster`-style ต่อเฟรมที่ความละเอียดลดลง หรือบันทึกเฉพาะ canvas ของฉากแล้วซ้อนเลเยอร์ — ตัดสินใจหลังวัดประสิทธิภาพ)
- เลือกความยาว 3/5/10 วิ + loop; รูปแบบ WebM/MP4 ตามที่เบราว์เซอร์รองรับ (ฟังก์ชัน `pickRecordMime`), Safari/iPad ต้องตรวจเป็นพิเศษ; ถ้าเบราว์เซอร์/webview ปิดการดาวน์โหลดให้มีทางสำรอง (Nava: `browserBlocksDownloads`, `showImagePreview`)
- แรงบันดาลใจ: Nava-art `pickRecordMime`, `startRecording`, `stopRecording`
- **ผ่านเมื่อ:** อัดได้ไฟล์เล่นได้ที่แสดง Kit หมุน/เส้นเต้นเคลื่อนไหว, ไม่ทำให้หน้าค้าง, มีตัวนับเวลา/ยกเลิก

## S7 — พู่กัน Tentacle/Branch + Symmetry

- **พู่กันชนิดใหม่ในเมนูปากกา:** Tentacle (เส้นอินทรีย์พลิ้วตามฟิสิกส์) และ Branch (เส้นแตกแขนงแบบเส้นเลือด/แม่น้ำ) — ตรงกับแนว vein/branching ในภาพอ้างอิง ("Tenacious")
- **Symmetry:** กระจก แนวตั้ง/นอน/หมุน N แฉก สำหรับปากกาและเส้น Line
- แรงบันดาลใจ: Nava-art `startTentacleBrush/updateTentacleBrush/drawTentacleBrushes`, `makeRootBranch/updateRootBranch`
- **ผ่านเมื่อ:** วาดแล้วได้ stroke ที่ undo/Save ได้ จำกัดจำนวนจุดเพื่อไม่หนัก

## S8 — ภาษาไทย/อังกฤษของเมนู Studio

- ตาราง `I18N = {en:{...}, th:{...}}` + `data-i18n` ที่ปุ่ม/หัวข้อ/ป้ายในแถบ (ไม่แปลชื่อฟอนต์/ศัพท์เทคนิคที่คนไทยใช้ทับศัพท์)
- ฟอนต์ไทยที่มีสระวรรณยุกต์ถูกต้อง (Noto Sans Thai/Sarabun) + เพิ่ม line-height ภาษาไทย (Nava: `html[data-lang="th"]`)
- สวิตช์ภาษาใน Settings, จำค่าใน localStorage
- แรงบันดาลใจ: Nava `applyI18n`, CSS `html[data-lang="th"]`
- **ผ่านเมื่อ:** สลับแล้วเมนูทั้งหมดเปลี่ยน ไม่มีข้อความล้นกล่อง ฟอนต์ไทยไม่ตัดวรรณยุกต์

## S9 — ของหนัก/เสี่ยง ทำท้ายสุด (ต้องคุยกับผู้ใช้ก่อนเริ่ม)

- **Fluid Wisps (น้ำสีไหล WebGL)** เป็นพื้นหลังเคลื่อนไหวใต้ดาว (Nava `FluidSim` ราวบรรทัด 4715) — WebGL สองชุดในหน้าเดียวบน iPad เสี่ยงหน่วยความจำ → ทดลองเป็นแผ่นแยก/ความละเอียดต่ำก่อน
- **ชั้น "ชีวิต" (planet/cloud/jelly/cell/venom/germ/black hole)** ลอยรอบดาว โปรเจกต์นี้มีปุ่ม Reset life อยู่แล้ว ต้องตรวจโค้ดก่อนว่าต่อกันได้แค่ไหน
- เล่นตามเสียงเพลง, บันทึกโปรเจกต์เป็นไฟล์ (.json นำเข้า/ส่งออก), คู่มือเริ่มต้น (onboarding) — ใช้ระบบเสียงเดิมของดาวและ Library ที่มี
- **WebGPU/GPU path ห้ามเริ่มจนกว่าผู้ใช้สั่ง** (เดิมรอผลจาก `chrome://gpu`)
